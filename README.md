# 🍕 2026 Pizza Sales & Profitability Excel Dashboard

An end-to-end Excel project transforming raw pizza order data into an interactive profitability dashboard using data cleaning, lookup functions, conditional calculations, PivotTables, and PivotCharts.

**Tools:** Excel | XLOOKUP | IFS | TRIM | Text Manipulation | PivotTables | PivotCharts | Slicers

---

## Project Overview

The objective of this project was to take raw pizza sales and delivery data, clean and transform it into an analysis-ready dataset, and build an interactive dashboard for evaluating profitability across restaurants, pizza types, toppings, and months.

---

The original dataset required cleaning and standardization before analysis. I used Excel's text and data-cleaning functionality to prepare the data for analysis.

<h3>Techniques Used</h3>

<ul>
<li><b>TRIM()</b> — Removed unwanted whitespace from text fields.</li>
<li><b>Text Splitting & Manipulation</b> — Separated combined fields into individual analytical fields.</li>
<li><b>Data Standardization</b> — Standardized inconsistent categorical values to ensure accurate aggregation.</li>
<li><b>Data Preparation</b> — Checked and prepared fields for lookup operations.</li>
<li><b>Data Validation</b> — Identified and handled inconsistencies that could affect analysis and aggregation.</li>
</ul>

<h1>2. Data Transformation</h1>

<h2>Functions & Techniques Used</h2>

<ul>

<li>
<b>XLOOKUP</b> — Connected information between related datasets and retrieved attributes needed for analysis.
</li>

<li>
<b>IFS</b> — Created conditional classifications and converted raw values into useful analytical categories.
</li>

<li>
<b>Conditional Calculated Columns</b> — Enriched the dataset with additional calculations designed to support the analysis.
</li>

<li>
<b>Text Manipulation</b> — Extracted and reorganized information from existing fields to create more usable analytical columns.
</li>

</ul>

The transformation process converted the cleaned source data into a more analysis-ready dataset containing additional fields such as delivery duration, distance, traffic level, peak-hour status, weekday, delivery efficiency, topping density, order month, and payment category.

---

<h1>3. PivotTables & PivotCharts</h1>

After transforming the data, I used PivotTables to aggregate the dataset and PivotCharts to visualize the results.

<h3>Analysis</h3>

<ul>
<li>Profit by Restaurant</li>
<li>Profit by Pizza Type</li>
<li>Profit by Topping Count</li>
<li>Profit by Month</li>
<li>Interactive filtering by Restaurant</li>
<li>Interactive filtering by Order Month</li>
</ul>

These PivotTables and PivotCharts served as the analytical foundation for the final dashboard.

<h1>4. Final Dashboard</h1>

<img width="893" height="393" alt="Pizza_Sales_Excel_Dashboard" src="https://github.com/user-attachments/assets/860a98c0-c1db-4004-9f39-88668869aa33" />

The final dashboard consolidates the analysis into an interactive reporting tool.

Slicers allow users to filter the analysis by **Restaurant Name** and **Order Month**, while the PivotCharts dynamically display profitability trends across restaurants, pizza types, topping counts, and months.

The dashboard provides a quick way to compare restaurant profitability, identify higher-performing pizza categories, evaluate topping-related trends, and observe changes in profitability throughout the year.
